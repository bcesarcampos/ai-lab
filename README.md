# ai-lab

A personal lab for AI-assisted experiments and tools.

## Scriptable Widgets

iOS widgets built with [Scriptable](https://scriptable.app), located in [Scriptable/](Scriptable/).

| Widget | Description |
|---|---|
| [motivation-widget.js](Scriptable/motivation-widget.js) | Configurable motivation widget with custom text, icon, and colors |
| [usd-brl-widget.js](Scriptable/usd-brl-widget.js) | Simple USD → BRL exchange rate widget |
| [usd-brl-with-graph-widget.js](Scriptable/usd-brl-with-graph-widget.js) | USD → BRL rate with historical graph |
| [usd-brl-converter-widget.js](Scriptable/usd-brl-converter-widget.js) | USD ↔ BRL converter widget |
| [google-calendar-widget.js](Scriptable/google-calendar-widget.js) | Google Calendar upcoming events widget |
| [yahoo-finance-news-widget.js](Scriptable/yahoo-finance-news-widget.js) | Yahoo Finance news feed widget |
